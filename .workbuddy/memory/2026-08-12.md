## 上午：bug 修复 + 业务集成

### Bug 修复（用户最关心）

**Bug 1：导出"提示重新打开浏览器页面下载"**
- 真因：axios 拦截器对 `responseType: 'blob'` 的响应同样走 JSON 错误码检查，当后端 401/403 返回 `{code:401,msg:'...'}` 时被解析成 Blob，再 `downloadBlob(blob, 'xxx.csv')` 把 JSON 当 CSV 写入磁盘，浏览器/Excel 打开失败
- 修复：下载改用原生 `fetch`，不走 axios 拦截器；非 2xx 自动转 `ElMessage.error`；文件名取服务端 `Content-Disposition: filename*=UTF-8''<encoded>`（之前整改时已就位）
- 涉及：`frontend/src/utils/download.js` 新增 `downloadBlobApi()`；`frontend/src/api/{student,completion}.js` 改用它；`StudentManage.vue` / `StudentPortal.vue` 调用点改为 `await export...(format)` 内部触发下载

**Bug 2：个别栏目"无网络"提示不友好**
- 真因：旧的 axios 拦截器把所有非 401/403 错误归类为 ElMessage.error(msg)，没区分超时/断网/onrender 休眠/5xx
- 修复：`frontend/src/api/request.js` 重写错误分类：
  - 401 → "登录已过期"（跳登录）
  - 403 → "无权限访问"
  - 404 → "接口不存在（404）"
  - 429 → "请求过于频繁"
  - 5xx → "服务暂时不可用"
  - `ECONNABORTED` → "请求超时"
  - `Network Error` → "网络连接中断"
  - 无 status + 离线 → "设备当前离线"
  - 无 status + 在线 → "服务器未响应（可能休眠/维护）"
