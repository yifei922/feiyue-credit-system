## 学生只显示20人 bug 修复（下午）

### 背景
用户截图：导入 54 人，学生管理只显示 20 人（截图含 18 行数据+2行隐藏）

### 根因
`server/src/util.js` 的 `paginate()` 函数**默认 pageSize=20**，而所有 `listStudents()` / `listTasks()` / `listSubjects()` 调用均**未传 pageSize 参数**，导致后端永远只返回第 1 页。

### DB 确认
```
sys_user: role=STUDENT n=54, role=ADMIN n=2, total=56
student: total=54
```
54 人全部在 DB 中，后端分页是唯一问题。

### 修复文件（6 个）
| 文件 | 修复内容 |
|---|---|
| `frontend/src/views/StudentManage.vue` | `listStudents({ pageSize: 200 })` |
| `frontend/src/views/Dashboard.vue` | `listStudents({ pageSize: 200 })` |
| `frontend/src/views/CompletionRegister.vue` | `listStudents({ pageSize: 200 })` |
| `frontend/src/views/StudentPortal.vue` | `listStudents({ pageSize: 200 })` |
| `frontend/src/views/RepPortal.vue` | `listTasks({ pageSize: 200 })` + `listSubjects('WEB', { pageSize: 200 })` |
| `frontend/src/views/SystemSettings.vue` | `listSubjects({ pageSize: 200 })` |
| `frontend/src/api/subject.js` | `listSubjects()` 支持第二参数 `extra` 传分页参数 |

## GitHub SSH 推送通道（下午）

### 关键发现
- Git Bash 环境 `git push` 卡住原因：环境变量注入的 safe-delete 工具拦截了 ssh-agent 交互式弹窗
- **解法**：改用 `GIT_SSH_COMMAND="ssh -o StrictHostKeyChecking=no"` 显式走 SSH 密钥验证
- remote 已切为 SSH：`git@github.com:yifei922/feiyue-credit-system.git`
- SSH key：`~/.ssh/id_ed25519.pub`（已注册 GitHub）

### push 命令（每次）
```bash
GIT_SSH_COMMAND="ssh -o StrictHostKeyChecking=no" git push origin master
```
