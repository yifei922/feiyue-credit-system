A2. 后端（新增运行器）

在 server/ 加 Vitest（node 模式）+ 一个示例测试，让 npm test 可用。

① 改 server/package.json 的 scripts，加 devDependencies：

{
  "scripts": {
    "start": "node src/index.js",
    "dev": "node --watch src/index.js",
    "test": "vitest run",
    "test:watch": "vitest"
  },
  "devDependencies": {
    "vitest": "^2.1.9",
    "supertest": "^7.0.0"
  }
}

② 新建 server/vitest.config.js：

import { defineConfig } from 'vitest/config'
export default defineConfig({
  test: { environment: 'node', include: ['tests/**/*.test.js'] }
})

③ 示例用例 server/tests/log.test.js（验证快照写入）：

import { describe, it, expect, beforeAll } from 'vitest'
import { recordLog } from '../src/services/log.js'
import { db } from '../src/db.js'

describe('operate_log 快照', () => {
  it('recordLog 写入前后快照', () => {
    recordLog({ id: 0, name: 'tester' }, 'UPDATE', 'task', 99,
      { title: '旧' }, { title: '新' })
    const row = db.prepare(
      'SELECT * FROM operate_log WHERE table_name=? AND record_id=? ORDER BY id DESC'
    ).get('task', 99)
    expect(row).toBeTruthy()
    expect(JSON.parse(row.before_snapshot).title).toBe('旧')
    expect(JSON.parse(row.after_snapshot).title).toBe('新')
  })
})

⚠️ 后端测试会真实写 server/data/*.sqlite，建议在 CI 用临时 DB 或测试前清空 operate_log。

阶段四 BDocker 化部署

现状：frontend/Dockerfile + frontend/nginx.conf 已存在，nginx 把 /api 反代到 backend:8080。 但没有 backend 镜像、没有 docker-compose，所以现在这套 Docker 跑不起来。补两个文件即可。

B1. 新建 server/Dockerfile

FROM node:22-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci || npm install
COPY . .
# node:sqlite 需 Node≥22.5（node:22-alpine 满足）
ENV NODE_ENV=production PORT=8080
EXPOSE 8080
CMD ["node", "src/index.js"]

B2. 新建根目录 docker-compose.yml

services:
  backend:
    build: ./server
    container_name: feiyue-backend
    ports: ["8080:8080"]
    environment:
      - NODE_ENV=production
      - PORT=8080
      - JWT_SECRET=${JWT_SECRET:-please-change}
      - WX_APP_ID=${WX_APP_ID:-}
      - WX_APP_SECRET=${WX_APP_SECRET:-}
    volumes:
      - ./server/data:/app/data      # 持久化 sqlite，避免容器重建丢数据
    restart: unless-stopped

  frontend:
    build: ./frontend
    container_name: feiyue-frontend
    ports: ["80:80"]
    depends_on: [backend]
    restart: unless-stopped
📌 关键点：后端 index.js:73 监听 process.env.PORT || 3001， 在 compose 里设 PORT=8080 即可与 nginx 反代对齐。sqlite 文件在 server/data，用 volume 挂载才不会随容器消失。

B3. 一键构建运行

docker compose up -d --build
# 验收：http://localhost  → 前端；  http://localhost/api/health → {"status":"ok"}

免费平台（Render）仍是单进程部署（见 render.yaml，构建前端 + 跑 node 服务同时托管 dist）。Docker 方案适合你自有服务器 / 内网部署。
