改后端地址

🔗 让小程序连上你的后端（重要！）

小程序默认连生产地址。要连你本机调试的后端，改这一行：

miniprogram/app.js   （第 6 行附近）
// 本机调试：改成下面这行
apiBase: 'http://localhost:3001'
// 生产环境：
// apiBase: 'https://feiyue-credit.onrender.com'
⚠️ 真机预览时手机访问不了 localhost（那是电脑自己）。要把 localhost 换成电脑局域网 IP，例如 http://192.168.1.100:3001，且后端要勾"不校验合法域名"才能连 HTTP。

下一步 ①

🪪 在微信公众平台完成身份证实名

打开 https://mp.weixin.qq.com → 用你扫码的那个微信登录 → 如果还没注册小程序，点「立即注册」→ 选「小程序」→ 填邮箱、验证码 → 进后台。

进后台后：「管理」→「基本信息」→ 主体信息「去完善」 → 上传身份证、人脸核验 → 完成个人实名。

💡 AppID wx0fe78d74fdc47c1b 已经是个人类型，如果这是你自己的号，直接去完善实名即可；如果是别人的号，需要重新用你自己的微信注册一个。
下一步 ②

🌐 配置「服务器域名」（小程序能联网的前提）

小程序上线后，wx.request 只能请求白名单里的 HTTPS 域名。设置路径：

公众平台后台 → 「开发」→「开发管理」→「开发设置」→「服务器域名」 → 在 request 合法域名 里加上：

https://feiyue-credit.onrender.com
⚠️ 白名单只收 HTTPS、且要 ICP 备案的域名。本机 localhost 不能填进去。所以：
• 开发调试 → 用开发者工具勾"不校验合法域名"即可；
• 正式发布 → 必须有一个 HTTPS+备案 的后端域名（如 onrender 提供的，或你自己的服务器）。
下一步 ③

🚀 提交审核 & 发布

在微信开发者工具点顶部 「上传」 → 填版本号（如 1.0.0）和备注 → 去公众平台后台 「版本管理」→「提交审核」 → 等 1~2 天审核 → 通过后点「发布」。

📌 审核前务必：勾掉"不校验合法域名"、确认服务器域名已配置、用真机扫码自己先测一遍主要流程。
🚨 重要安全提醒：AppSecret 是小程序的最高密钥，绝不能发给任何人、不能写进代码、不能发到群里。如怀疑泄露，立即在公众平台「开发设置」里重置 AppSecret。

4常见问题 & 避坑

Q1

开发者工具打开项目是空白/报错？

90% 是目录选错。目录必须精确到 …\miniprogram（包含 app.json 那层），不能选到 feiyue-credit 根目录。

Q2

登录/发帖一直转圈或报网络错误？

后端没启动，或没勾"不校验合法域名"。先确认你双击过 run-node.bat 且窗口显示"已启动：http://localhost:3001"，再在工具里勾对应选项。

Q3

改了代码手机没变化？

保存一下文件（Ctrl+S），开发者工具会自动编译。若还不行，点工具栏「编译」按钮，或「清缓存」→「全部清除」。

Q4

个人小程序能接"微信登录手机号"吗？

不能，getPhoneNumber 需要企业认证。本项目已用 wx.login → openid 方案替代，个人完全可用，无需手机号。

Q5

AppID 填不上 / 提示无权限？

说明这个 AppID 不是你微信名下的。用你自己的微信去 mp.weixin.qq.com 注册一个属于你的小程序，拿到新 AppID 再导入。
