# 小程序后端部署方案（点滴进步 · 个人主体）

> 结论先行：**小程序后端用「微信云托管 CallContainer」调用，可做到免域名、免 ICP 备案**，
> 直接绕开"onrender 是海外节点无法备案"的死结。网络端 feiyue-credit.onrender.com 保持原样，
> 两者审核与运营互不影响。

---

## 一、为什么这是个真问题

- 小程序正式发布时，`wx.request` 调用的 `request合法域名` **必须**满足：HTTPS + 中国大陆 ICP 备案 + 在微信公众平台配置。
- `feiyue-credit.onrender.com` 是海外节点，**通常无法做中国大陆 ICP 备案** → 不能直接当小程序后端域名。
- 网络端（学分管理系统）保留在 onrender 给海外/演示用，**不受影响**，也不进入小程序审核范围。

---

## 二、三个方案对比

| 方案 | 是否需要备案 | 代码改动 | 成本 | 适合谁 |
|------|------------|----------|------|--------|
| **A. 微信云托管 + CallContainer（推荐）** | **否**（走微信私有协议，小程序内调用免域名免备案） | 小：现有 Node 服务打包成容器；调用层 `wx.request`→`wx.callContainer` | 按量计费，有免费额度（约 ¥0 起步） | 想最快上线、不想碰备案/服务器的个人开发者 |
| **B. 国内轻量云 + 自有备案域名** | **是**（需 1–2 周个人 ICP 备案） | 极小：代码原样部署，只改 `API_BASE` | 轻量云 ~¥100/年 + 域名 ~¥50/年 | 想完全掌控服务器、沿用现有 sqlite 文件库 |
| C. 纯云开发云函数 | 绑自定义域名时才需备案 | 大：后端重写成云函数 + 云数据库 | 按量，有免费额度 | 不推荐（对现有 Express 代码不友好） |

---

## 三、推荐方案 A 详解：微信云托管（Cloud Run）

### 原理（已查官方文档确认）
- 小程序用 `wx.callContainer` 调用云托管服务，**无需域名、无需在 mp 后台配置服务器域名、无需备案**。
- 后端可直接从 HTTP header 拿到 openid 等登录态，无需自己维护 access_token。
- **注意**：云托管的「默认公网域名」仅用于接口测试，**不能**用于生产，也不能在 mp 后台配置；生产请走 CallContainer（内网/微信私有协议）。
- **容器不支持持久化存储**，现有 `node:sqlite`（文件库）需迁到外部数据库（腾讯云数据库 MySQL 基础版，或云开发数据库）。

### 落地步骤
1. 微信公众平台 → 微信云托管，开通环境，得到**环境 ID**（填进 `env.js` 的 `CLOUD_RUN_ENV`）。
2. 把现有 Node 服务做成 Docker 镜像（加一个 `Dockerfile`，基础镜像 `node:18-alpine`，`npm start`）。
3. 推送镜像到云托管，部署服务。
4. 数据库：新建一个腾讯云数据库 MySQL（基础版，按量很低）或云开发数据库，把 `server/` 的建表/连接指向它。
5. 小程序调用层改造：`wx.request({ url: API_BASE + path })` → `wx.callContainer({ config: { env: CLOUD_RUN_ENV }, path, ... })`。
6. `env.js` 设 `IS_PROD=true`、`USE_CLOUD_RUN=true`，上传代码审核。

### 与网络端的数据关系
- 若小程序与 onrender 网页端**需要共享数据**：云托管可绑「自定义域名」（需备案）供网页端公网调用；或两者各自独立后端（最简单，符合"并行独立运营"）。
- 当前建议：**先各自独立**（小程序走云托管、网页端走 onrender），数据不强制打通，待上线稳定后再决定是否合并。

## 四、备选方案 B 详解：国内轻量云 + 备案域名

### 步骤
1. 买大陆节点轻量应用服务器（阿里云/腾讯云，约 ¥100/年）。
2. 注册一个域名（.cn/.com 约 ¥50/年），做**个人 ICP 备案**（腾讯云/阿里云代提交，管局审核约 1–2 周，免费，需实名+拍照）。
3. 把 `server/` 原样部署到该服务器（sqlite 文件库可继续用，服务器有磁盘）。
4. `env.js` 设 `IS_PROD=true`、`USE_CLOUD_RUN=false`、`API_BASE='https://你的备案域名.com'`。
5. 微信公众平台 → 开发设置 → 服务器域名 → 把该域名加入 `request合法域名`。
6. 上传代码审核。

### 优点 / 缺点
- 优点：代码几乎零改动，sqlite 直接沿用，完全自主。
- 缺点：要等 1–2 周备案、要自己管服务器、有年费。

---

## 五、时间线与建议

| 阶段 | 动作 | 周期 |
|------|------|------|
| 现在 | 改好 `env.js`（已完成）、确认小程序合规内容 | 即时 |
| 选 A | 开通云托管、做 Docker、改调用层、部署 | 1–3 天 |
| 选 B | 买服务器+域名、提交备案、部署 | 备案 1–2 周 + 部署 1 天 |
| 收尾 | 小程序提交审核 → 过审 → 小程序备案 → 发布 | 审核 1–3 天 |

**一句话建议**：想最快、最省心上线 → 选 **A（微信云托管）**，连备案都省了；
想完全掌控、不怕等备案 → 选 **B（轻量云+备案域名）**，代码改动最小。
