微信审核结果会微信通知你。通过后「开发版本」变成「审核通过版本」，点一下就发布上线。

💡 发布前记得确认「小程序备案」已在走流程（见你后台第①步第3项），最晚上架前通过即可；「微信认证」不强制，但认证后才能用搜索和分享朋友圈。

第二部分　服务器 & 域名配置

A

配置 AppID / AppSecret

后端要靠这对凭证帮用户换登录态，必须填正式小程序的，不能用测试号。

界面示意 · 公众平台 → 开发管理 → 开发设置
 开发设置

AppSecret 只显示一次，复制保存好；丢失需重新重置

操作步骤：公众平台 →「开发管理」→「开发设置」→ 复制 AppID（你已是 wx0fe78d74fdc47c1b）→ 点 AppSecret 的「重置 / 生成」拿到密钥 → 填进服务器。

填到你项目的 server/.env 文件（没有就复制 .env.example 改名）：

# server/.env （不要把 .env 提交到代码仓库）
WX_APP_ID=wx0fe78d74fdc47c1b
WX_APP_SECRET=你刚重置拿到的密钥
JWT_SECRET=一串随机字符串(生产必须)
DB_HOST=你的MySQL地址  # 云托管/腾讯云MySQL
⚠️ AppSecret 是敏感信息，绝不要写进前端代码或提交到 git。后端放在服务器环境变量里。
B

配置服务器域名（request 合法域名 / 云托管免配）

小程序默认只能请求白名单里的 https 域名。但用「微信云托管」可以免掉这一步。

方案 B（推荐）：云托管免配域名

在 miniprogram/config/env.js 改成下面这样，小程序走微信私有协议调用后端， 不需要在后台配任何域名，也不需要 ICP 备案：

const IS_PROD = true;
// PROD 对象里：
USE_CLOUD_RUN: true,
CLOUD_RUN_ENV: '你的云托管环境ID',
CLOUD_RUN_PUBLIC_HOST: 'xxxx.ap-shanghai.run.tcloudbase.com'
💡 云托管环境ID和默认公网域名在：公众平台 → 左侧「云托管」→ 开通后获取。详细见 docs/cloudrun-deploy.md。

方案 A：自有备案域名（才需要配白名单）

界面示意 · 开发设置 → 服务器域名
 服务器域名

必须是 https，且域名已完成 ICP 备案

操作步骤（仅方案 A 需要）：公众平台 →「开发管理」→「开发设置」→「服务器域名」→ 填你的 https 域名到 request / uploadFile / downloadFile 三栏 → 保存。

⚠️ 域名必须是 https 且 已 ICP 备案；同时把 env.js 的 API_BASE 改成 https://你的备案域名.com、USE_CLOUD_RUN=false。
对比方案 A 自有备案域名方案 B 云托管（推荐）
是否要配服务器域名要不用
是否要 ICP 备案要不用
上线速度慢（等备案）快
C

业务域名 + SSL 证书绑定（免费）

「业务域名」用于网页授权/内嵌网页等场景；SSL 证书让域名支持 https（小程序强制要求）。

1) 免费 SSL 证书（HTTPS）

腾讯云 / DNSPod 提供 免费 DV 证书（1 年期），够小程序用：

登录腾讯云 SSL→ 申请免费证书→ DNS 验证→ 下载部署到服务器

免费证书入口：腾讯云控制台 →「SSL 证书」→「免费证书」→ 选 DV 型 → 填域名 → 按提示做 DNS 解析验证 → 下载并部署到你的 Web 服务器 / 云托管。

2) 配置业务域名

界面示意 · 开发设置 → 业务域名
 业务域名

需下载校验文件 → 放到域名根目录 → 点「保存」自动校验

操作步骤：公众平台 →「开发管理」→「开发设置」→「业务域名」→ 填域名 → 下载 校验文件.txt → 放到你服务器网站根目录（能被 https://域名/校验文件.txt 访问到）→ 回后台点「保存」即可通过校验。

⚠️ 如果走「方案 B 云托管」，业务域名通常也不用配（云托管自带 https 与合法调用通道）。免费证书主要服务于「方案 A 自有域名」。
💡 对小白最省事的路线：直接用云托管（方案 B），SSL、域名白名单、备案一次性全免，只剩「申请云托管环境 + 填 env.js」两件事。
✅ 一句话路线（小白推荐）：下载开发者工具 → 导入 miniprogram → 改 env.js（IS_PROD=true+USE_CLOUD_RUN=true）→ 上传 1.0.0 → 加体验成员 → 提审（测号 student01/123456）→ 过审发布；后端用云托管部署（详见 cloudrun-deploy.md），域名/备案/SSL 全免。
