1下载：去哪下、下哪个版本

只用官网，别去第三方软件管家下（容易带广告或旧版）。

第 1 步

🌐 打开官方下载页

在浏览器地址栏输入（复制粘贴最保险）：

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

回车后看到如下页面（示意）：

第 2 步

💾 下载 & 确认文件

点「Windows 64位」后浏览器开始下载，得到一个安装包（名字类似）：

wechat_devtools_1.06.xxxxx_x64.exe
💡 下载很慢是正常的（官网有时限速）。如果卡住，换浏览器或挂网络重试，不要从百度搜的"高速下载"下。
⚠️ 怎么知道自己是 64 位还是 32 位？
桌面「此电脑」右键 →「属性」→ 看「系统类型」：写"64 位"就选 64 位；老电脑写"32 位"才选 32 位（现在极少）。拿不准就选 64 位。

2安装：一路"下一步"

装到哪都行，默认 C 盘最省事。

步骤

🔧 双击安装包

双击下载好的 .exe → 弹出安装向导：

① 同意协议勾"我已阅读"→ 点「下一步」
② 选路径默认 C 盘，直接「下一步」
③ 快捷方式默认打钩 →「下一步」
④ 安装点「安装」，等进度条跑完

进度条走完 → 点「完成」→ 桌面出现绿色图标 微信开发者工具，双击就能打开。

💡 若提示"是否允许此应用更改设备"，点「是」。杀毒软件弹窗也一律「允许/信任」。

3首次启动 & 微信扫码登录

第一次打开会让你用微信扫码，这一步就是"个人身份证实名"的入口。

登录

📱 用你自己的微信扫码

① 打开工具后，出现二维码界面

② 拿出你自己的手机微信 → 扫一扫

③ 手机上点「登录」→ 电脑自动进入

💡 用谁的微信扫码，这个小程序就归谁。要发布到自己名下，就用你自己的微信。

登录后进入「项目列表」页（暂时是空的，因为我们还没导入项目）。

4导入本项目（关键步骤）

把电脑里的小程序代码"装"进工具里。目录和 AppID 千万别填错。

填写

📂 点「导入项目」并填 3 项

① 目录（最重要，精确到 miniprogram 那层）：

C:\Users\20242\WorkBuddy\feiyue-credit\miniprogram

② AppID：

wx0fe78d74fdc47c1b

③ 项目名称：随便写，如 飞越学分

🚫 目录填错是最常见的新手错误！
• ❌ 错：C:\Users\20242\WorkBuddy\feiyue-credit（根目录，不含 app.json）
• ✅ 对：…\feiyue-credit\miniprogram（含 app.json 的那层）
填错会提示"不是小程序项目"或打开空白。
必勾

✅ 开发阶段先勾「不校验合法域名」

导入后如果登录/提交报错（"url not in domain list"），是因为工具默认只允许连备案过的 HTTPS 域名。开发时：

右侧点 详情 → 「本地设置」→ 勾选 ✅ 不校验合法域名、web-view（真机调试时也勾）。

💡 这个选项只影响你本地开发。正式发布上线时，要去公众平台配"服务器域名"白名单（见上一份指南第 3 节）。

5认识界面：4 个区域各干什么

第一次打开可能觉得乱，其实就是"上工具栏 + 左手机 + 中代码 + 下调试"。

区域它干嘛用你平时怎么用
🔝 顶部工具栏编译/预览/上传/详情改完代码点「编译」刷新；要手机看就点「预览」
📱 ① 模拟器手机画面，真实效果点底部 tab、点按钮，试用你的小程序
⌨️ ② 编辑器左侧文件树 + 右侧代码双击文件打开，改文字/颜色，Ctrl+S 保存
🐞 ③ 调试器Console 报错 / Network 请求出错了看这里红字；登录失败看 Network 请求

6日常怎么用（最常用 4 个动作）

动作 1

🔄 改了代码怎么看效果

在编辑器里改完 → 按 Ctrl+S 保存 → 工具自动编译，左边手机立刻变样。没变就点顶部 编译。

动作 2

👀 想用真手机看 → 点「预览」

顶部点 预览 → 生成一个二维码 → 手机微信扫码 → 小程序跑在你真手机上。适合发给别人试。

动作 3

🐞 出错了去「调试器」看原因

底部「调试器」切到 Console 看红色报错；切到 Network 看请求是否成功（正常是绿色 200）。把红字截图发我，我帮你定位。

💡 如果 Network 里请求是红色/失败，多半是后端没启动（双击 run-node.bat）或没勾"不校验合法域名"。
动作 4

🚀 要发布了 → 点「上传」

开发完成、自测没问题 → 顶部点 上传 → 填版本号（如 1.0.0）→ 去公众平台后台「提交审核」。（详细见上一份指南第 3 节）

7新手避坑 & 常见问题

Q1

安装时一直转圈 / 卡住？

关掉杀毒/电脑管家再装；或右键安装包「以管理员身份运行」。阿里电脑管家有时会拦，先退出它。

Q2

打开工具提示"微信未安装"？

电脑上得先装电脑版微信并登录。去 https://weixin.qq.com 下载安装微信 Windows 版，登录后再开工具。

Q3

导入后界面空白 / 提示不是小程序？

目录填错了。确认选到 …\feiyue-credit\miniprogram（里面要有 app.json）。

Q4

预览/真机扫码打开是白屏？

后端没连上。先双击 run-node.bat 确认服务器起来，再在「详情→本地设置」勾"不校验合法域名"。

Q5

工具卡顿、反应慢？

顶部「清缓存」→「全部清除」；或关掉「调试器」「编辑器」中不用的面板（点工具栏对应文字切换显示/隐藏）。

🚨 记住：工具里看到的画面 = 手机上的样子。只要模拟器里能正常登录、发帖、提交，就说明代码没问题，可以放心往上发。
