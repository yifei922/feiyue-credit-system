0先看清全貌：上线要过哪几关

不用死记，记住这条链路就行：配广告 → 配密钥 → 绑域名 → 部署后端 → 上传小程序 → 验证。

1申请微信"流量主"广告位

目标：拿到两个广告位 ID，填进小程序，这样开屏和"看广告看资料"才出现真实广告（产生收益）。

  1. 电脑浏览器打开 mp.weixin.qq.com → 用你的小程序管理员微信扫码登录。
  2. 左侧菜单 流量主 → 广告位管理 → 分别创建：
    • 插屏广告（对应开屏广告）→ 记下 adunit-xxxx
    • 激励视频广告（对应"看广告解锁资料"）→ 记下 adunit-xxxx
  3. 打开小程序项目里的文件 miniprogram/config/ad-config.js，把两个占位符替换成真实 ID：
    // 改前 const SPLASH_AD_UNIT_ID = '__WX_AD_SPLASH__'; const REWARD_AD_UNIT_ID = '__WX_AD_REWARD__'; // 改后（举例） const SPLASH_AD_UNIT_ID = 'adunit-1a2b3c4d5e6f'; const REWARD_AD_UNIT_ID = 'adunit-7g8h9i0j1k2l';
⚠️ 门槛提醒：个人主体需"累计独立访客 ≥ 1000"才能开通流量主。没达标前，小程序里的广告位会自动"放行"（不弹广告也能看资料），不影响使用，只是没收益。达标后再填 ID 即可。

2填入真实微信 AppSecret（让真实微信用户能登录）

目标：把占位符换成你小程序的真实密钥，否则同学们用自己微信登录会失败。

  1. 在 mp.weixin.qq.com 左侧 开发 → 开发设置 → 开发者ID 找到 AppSecret，点"重置/获取"（需管理员扫码），复制那串密钥。
  2. 打开服务器配置 server/.env（你本地这份），把：
    WX_APP_SECRET=请替换为重置后的真实AppSecret # 改成： WX_APP_SECRET=你复制的真实密钥
  3. 同一文件里，务必删除或注释掉 WX_MOCK=1 这一行（它只是本地预览用，留着会让"任意 code 都能登录"，有安全风险）。
    # 删掉这行（或前面加 # 注释）： # WX_MOCK=1
🔒 安全说明：系统已做加固——只要服务器设置了 NODE_ENV=production（下一步），即使你忘记删 WX_MOCK，真实环境也不会开启假登录。但养成良好的习惯：上线就删掉它。

3设置 JWT 登录签名密钥

目标：给"用户登录后发的令牌"换一把只有你知道的锁，防止被伪造。

  1. 在 server/.env 里，把 JWT_SECRET 从占位符换成一段随机长串。
  2. 最简生成法（在终端执行，把输出结果抄进去）：
    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  3. 把得到的 64 位十六进制串填进去：
    JWT_SECRET=这里粘贴生成的随机串

4配置服务器域名白名单（小程序才能联网）

目标：告诉微信"允许这个小程序去哪个网址请求数据"。不配，真机打开小程序会报"不在合法域名"而无法登录/看资料。

  1. 准备一个 https 域名（部署后你就有了，例如 https://feiyue.xxx.com）。
  2. 在 mp.weixin.qq.com → 开发 → 开发设置 → 服务器域名：
    • request 合法域名：添加你的 https 域名，例如 https://feiyue.xxx.com
    • uploadFile / downloadFile 合法域名：同样加上（用于上传头像等）
  3. 业务域名：本系统资料是用"复制链接→浏览器打开"，不依赖 web-view，所以业务域名可暂不填。若以后想在小程序内直接打开网页，再配"业务域名"并下载校验文件放到服务器根目录。

5部署后端到服务器（3 种方式任选）

目标：让后端 7×24 小时在线，同学随时能访问。选你最顺手的一种。

  1. 方式 A（最简单，自有电脑/轻量服务器）：把整个项目文件夹拷过去，双击 run-node.bat 即可。它会自动装依赖、构建、启动在 3001 端口。记得在 server/.env 里加一行 NODE_ENV=production（安全必须）。
  2. 方式 B（推荐·免费·Render）：把代码推到 GitHub，在 Render 新建 Web Service 连仓库，Build 命令 npm install、Start 命令 node server/src/index.js，并在环境变量里设 NODE_ENV=production、WX_APP_SECRET、JWT_SECRET、PORT=8080。Render 会给你一个 https://xxx.onrender.com 域名。
  3. 方式 C（Docker）：项目已带 docker-compose.yml，在有 Docker 的机器上 docker compose up -d 即可。
🌐 无论哪种方式，最终你会得到一个 https 域名。这个域名要回填到：① 步骤4 的微信白名单；② 小程序里的 API 地址（下一步）。

6小程序端：改地址 → 上传 → 提交审核

目标：让小程序知道去哪个网址取数据，并把它提交到微信审核、发布。

  1. 打开 miniprogram/config/env.js，把 API 地址改成你的 https 域名：
    // 改前（本地） API_BASE: 'http://localhost:3001', // 改后（线上） API_BASE: 'https://feiyue.xxx.com',
  2. 打开 微信开发者工具 → 导入项目（选 miniprogram 文件夹）→ 填你的 AppID：wx0fe78d74fdc47c1b。
  3. 点右上角 上传，填版本号（如 1.0.0）和备注 → 上传成功。
  4. 回到 mp.weixin.qq.com → 版本管理 → 开发版本 点"提交审核" → 按提示填写功能页面与类目（选"教育-在线教育"类）→ 提交。
  5. 审核通过（通常 1–2 天）后，在 版本管理 → 线上版本 点"发布"。发布后，微信里搜小程序名即可搜到。

10常见坑 & 排查清单

上线不顺时，按顺序自查：

  • 真机打开小程序报"不在合法域名" → 步骤4 的 request 域名没配或没填 https
  • 微信登录提示"服务器端未配置微信" → 步骤2 的 AppSecret 没填真实值 / WX_MOCK 没删
  • 看资料一直说"需看广告"却没广告弹 → 流量主未开通，属正常（开发阶段自动放行），开通后填步骤1 的 ID
  • 资料点开是空白/打不开 → 确认后端 /study 静态目录已随项目部署（server/study-content）
  • 改完小程序地址不生效 → 改的是 miniprogram/config/env.js，改完要重新"上传"版本
  • 本地能跑、线上 404 → 检查线上是否设了 NODE_ENV=production 且后端进程在跑
