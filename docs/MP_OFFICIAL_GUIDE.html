二、转正式个人小程序：分步实操（全人工）

💡
「个人主体」小程序用你本人的微信 + 身份证就能注册，注册免费。注意：个人主体不能做微信支付、部分类目受限，但你的「班级学分管理 + 资料 + 广告」完全够用。流量主对个人主体开放。
1
用电脑浏览器打开注册页
访问 https://mp.weixin.qq.com/ → 右上角点「注册」。不要用你截图里那个带 sandbox 的测试号地址。
2
选账号类型
填邮箱（建议用新邮箱，别和测试号混）→ 验证码 → 密码。邮箱会收到激活链接，点开激活。
3
选择「小程序」类型
激活后会让选账号类型，务必选 小程序（不是公众号/服务号）。
4
主体信息登记 = 个人
主体类型选「个人」→ 填你的姓名、身份证号 → 用你本人微信扫码完成实名（扫码的微信号就是该小程序的「管理员」）。
注意 一个身份证只能注册 1 个个人小程序；一个微信号最多管 5 个小程序。
5
填写小程序基本信息
登录后进入后台 → 左侧「设置 → 基本设置」：
• 名称：如「飞跃学分」或「洛一高附中八⑩班」
• 图标：传一张 144×144 的 logo
• 类目：选「教育 → 学校教育」或「工具 → 信息查询」（个人主体建议选工具类更稳过审）
免费 个人小程序基础信息登记免费，不用交 300 元认证费（那是企业主体的微信认证）。
6
拿到正式 AppID 和 AppSecret
左侧「开发 → 开发管理 → 开发设置」：
• 复制 AppID（wx 开头，和测试号不同！）
• 点「生成 / 重置 AppSecret」→ 扫码 → 立即复制保存（只显示一次！）
关键 这个 AppSecret 才是能用于生产的，你之前给的 cfa72807… 是测试号的，生产无效。
7
配置服务器域名（真机生效）
同一页「服务器域名」板块 → 点「修改」→ 用管理员微信扫码：
• request 合法域名 添加：https://feiyue-credit.onrender.com
• uploadFile / downloadFile 合法域名：同样加 https://feiyue-credit.onrender.com
• socket 合法域名：留空即可
已做 你测试号里其实已填过这个域名，但那是测试环境，正式号必须重新在正式后台填一遍。
注册 mp.weixin.qq.com→ 主体=个人+实名→ 填基本信息→ 拿 AppID/AppSecret→ 配服务器域名→ 改项目文件→ 上传+审核+发布

三、拿到正式 AppID 后：改 3 个文件

① miniprogram/project.config.json

// 把 appid 从测试号换成正式号（示例，换成你真实的）
"appid": "wxXXXXXXXXXXXXXXXX",   // ← 改成第二节第6步复制的正式 AppID

② miniprogram/config/env.js

// 本地预览用 localhost；但「上传代码」发布时要用线上域名
module.exports = {
  API_BASE: 'https://feiyue-credit.onrender.com',  // ← 改成你的线上地址（和域名白名单一致）
};
⚠️
发布版必须用 https:// 域名，不能用 localhost。如果你平时要在本地调试，可临时改回 localhost，上传前再改回线上域名。

③ server/.env（后端，见第四节）

四、server/.env 填真实配置（后端生产）

打开 server/.env，把下面几项改成真实值：

# 微信小程序凭证（换成正式小程序的，不是测试号！）
WX_APP_ID=wxXXXXXXXXXXXXXXXX
WX_APP_SECRET=你第二节第6步复制的正式AppSecret

# ❌ 删除这一行（否则生产仍走 MOCK，真实用户登录会失败）
WX_MOCK=1

# JWT 密钥：必须改成随机长字符串（生成命令见文件内注释）
JWT_SECRET=把这里换成 node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" 的输出

# 积分规则（保持）
INIT_POINTS=100
RESOURCE_VIEW_COST=5

# 生产环境标记（Render/Docker 部署时务必加）
NODE_ENV=production
✅
改好后：删掉 WX_MOCK=1 并设 NODE_ENV=production，微信登录就关闭 MOCK、强制走真实 code2Session，真实用户才能登录。

五、重新部署上线

  1. 推代码到 GitHub（Render 会自动重新构建部署）： 
    git add -A
git commit -m "生产配置：正式AppID+关MOCK+NODE_ENV=production"
git push
  2. 在 Render 后台确认环境变量：登录 render.com → 你的 Web Service → Environment → 确保 WX_APP_ID、WX_APP_SECRET、JWT_SECRET、NODE_ENV=production 都已填（Render 上填的会覆盖仓库里的 .env）。
  3. 等部署完成：Render 显示 「Live」后，访问 https://feiyue-credit.onrender.com/api/health 应返回 {"ok":true}。
  4. 微信开发者工具「上传」代码：打开项目（AppID 已改正式号）→ 右上「上传」→ 填版本号（如 1.0.0）和备注 → 提交。
  5. 提审 + 发布：回正式小程序后台 → 「管理 → 版本管理 → 开发版本」→ 提交审核 → 等 1~3 天审核 → 通过后点「发布」。
💡
审核期间不影响你本地测试；审核通过后用户才能在微信里搜到并使用。

六、上线后必须人工联调联试的全部事项

以下这些无法自动化、必须你本人操作或真机验证。建议逐项打勾：

🔐 A. 认证 / 登录（最关键）

  • ☐ 真机扫码登录：用另一部手机（或退出开发者工具）微信扫小程序码，点「微信一键登录」，应能成功进入、看到「我的」页有用户信息。 人工
  • ☐ 确认没走 MOCK：登录后，后端日志不应出现 [wx] MOCK 字样；或看数据库 user 表 openid 是真实 oXXXX 而非 mock_xxx。 人工+日志
  • ☐ 新用户赠 100 积分：真机首次登录后，「我的」页积分应为 100。 人工

🌐 B. 域名 / 网络（真机才暴露）

  • ☐ request 域名生效：真机打开小程序，首页能拉到资料列表（不再报「url 不在合法域名」）。 人工·真机
  • ☐ uploadFile 域名生效：「我的 → 上传头像」能成功上传（个人资料编辑依赖它）。 人工
  • ☐ 资料链接可打开：点资料「打开/复制链接」→ 浏览器能打开 https://feiyue-credit.onrender.com/study/xxx.html。 人工

📢 C. 广告流量主（需先申请）

  • ☐ 申请流量主：正式后台 → 「流量主 → 开通」，需累积 ≥1000 用户才能申请（个人主体同样适用）。 人工·有门槛
  • ☐ 填广告位 ID：申请通过后，把「开屏广告位 ID」「激励视频广告位 ID」填进 miniprogram/config/ad-config.js，重新上传代码。 人工+改码
  • ☐ 真机看广告：开屏广告出现、打开资料弹激励视频、看完才能看资料。 人工·真机
  • ☐ 没填广告位时优雅跳过：未配置时小程序不应崩溃，仅静默不显示广告（已做容错）。 已处理

⭐ D. 积分 / 资料 / 管理端

  • ☐ 查阅扣 5 积分：真机打开一条资料，积分从 100 → 95。 人工
  • ☐ 积分不足拦截：积分不够时，应提示「积分不足，请看广告或联系老师」。 人工
  • ☐ 管理后台入口：老师/管理员角色的「我的」页出现「管理后台」，能进资料管理、用户管理。 人工·需管理员账号
  • ☐ 资料已填充：初一/初二/初三各有复习资料（服务器启动自动播种 22 条）。 已处理

🧪 E. 用脚本做接口自测（可半自动）

  • ☐ 部署后跑：
    node tools/endpoint_test.mjs https://feiyue-credit.onrender.com
    看是否全 ✅（登录、资料、管理端、静态 HTML、404）。
  • ☐ 注意：脚本里「微信登录」那项在真机 MOCK 关闭后会要求真实 code，脚本用假 code 会得到 401 —— 这是正常的，说明生产已关闭 MOCK；真机登录才走通。

七、必看：最容易卡住你的 5 个坑

现象原因解决
真机打开小程序白屏/拉不到数据服务器域名没在正式后台配，或配的还是测试号第二节第7步，正式后台重新加域名
点微信登录一直「服务器端未配置微信」.env 还留着 WX_MOCK 或 AppSecret 是测试号的第四节：换正式 AppSecret、删 WX_MOCK、设 NODE_ENV=production
开发者工具只显示欢迎页项目没正确导入 / AppID 不匹配工具里「导入项目」选 miniprogram 目录，AppID 填正式号
上传头像失败uploadFile 合法域名没配正式后台加 uploadFile 域名
审核被拒类目不符 / 名称含「学校」需资质类目改「工具→信息查询」；名称避免用具体校名
✅
一句话总结流程：注册正式个人小程序（拿真 AppID/AppSecret）→ 正式后台配域名 → 改 3 个文件 → 填 .env 并删 WX_MOCK → 推 GitHub 触发 Render 重部署 → 开发者工具上传代码 → 提审发布 → 真机逐项联调（登录/积分/广告/头像上传）。
