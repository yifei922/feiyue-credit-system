# feiyue-credit Web 端广告变现研究方案（2026-08-11）

> 研究对象：`https://feiyue-credit.onrender.com/login#`（Render 托管的 Vue3 SPA 管理后台）
> 核心结论：当前形态**无法直接接 Web 广告**，必须先自建「公开内容页 + 流量」，再接 AdSense/Adsterra。

---

## 一、现状诊断（为什么现在不能放广告）

| 项 | 现状 | 对广告的影响 |
|----|------|--------------|
| 页面性质 | Vue SPA，哈希路由 `/login#/dashboard`，**需登录** | AdSense 直接拒（「网站内容不足/登录墙」）；无公开可抓内容 |
| 内容 | 纯功能后台，无文章/博客 | 广告无展示位、无流量、无上下文 |
| 域名 | `*.onrender.com` 子域 | AdSense 要求**自定义域名**；onrender 免费实例**闲置休眠**（抓取时慢，伤 SEO） |
| 流量 | 仅你自己/管理员访问 | 广告曝光≈0，毫无收益 |

**一句话**：在登录后台插广告 = 既违规又没收入。必须另起「公开内容站」。

---

## 二、AdSense vs Adsterra 对比（2025/2026 实测）

| 维度 | Google AdSense | Adsterra |
|------|----------------|----------|
| 最低流量门槛 | 建议 1k+ 月访问，内容 15–30 篇原创 | **无最低流量要求** |
| 审核周期 | 7–14 天，通过率约 65% | **10 分钟内**审批 |
| 内容要求 | 原创≥60%、About/Contact/Privacy、禁登录页/纯产品页 | 真实人类流量即可，禁恶意软件/钓鱼 |
| 收益模型 | CPC $0.1–10+；CPM $0.5–10+（RPM 高） | CPM $1–3/千次（display），popunder CPC 更高 |
| 收益水平 | 高（金融/科技/健康 niche RPM 高） | 中低，但稳定 |
| 最低提现 | $100 | **$5**（Paxum/PayPal/ BTC/ wire） |
| 付款周期 | 次月 21 日 | 每周/双周 |
| 广告形式 | 展示/原生/信息流/锚点（偏克制） | Popunder/Social Bar/Native/Interstitial（偏重） |
| 域名要求 | **必须自定义域名** | 子域也可，建议自有域 |

> 关键红线：AdSense **禁止在纯产品页/加购页/登录页**投广告，且**严禁点击自家广告**（单 IP 高频点击永久封号）；食养/健康类内容若宣称疗效，会被判「医疗保健违规」直接拒——与你的 `pdd-gaofang-merchant` 技能「禁疗效宣称」规则一致。

## 三、推荐路径：Adsterra 起步 + AdSense 冲高（双轨）

1. **即时变现层（Adsterra）**：无门槛、当天拿代码嵌入公开页，哪怕日几十 UV 也有几毛~几刀收入，先覆盖 onrender 托管费。
2. **高收益层（AdSense）**：同步建设原创内容站（食养科普），达标后申请，RPM 显著高于 Adsterra。
3. **不二选一**，两者广告位可并存（AdSense 展示+Adsterra 原生/弹窗互补）。

## 四、落地到你的代码（frontend/ 是 Vue3 SPA）

### 4.1 新增公开路由（与 /login 后台并列，无需登录）
在 `frontend/src/router` 增加公开页面：
- `/` 或 `/home` —— 公开落地页（产品介绍 + 食养科普入口）
- `/blog` + `/blog/:slug` —— 科普文章列表/详情（Markdown 渲染）
- `/about` `/privacy` `/contact` —— 合规必备页（AdSense 强要求）
- 这些路由**不进登录守卫**，SSR/静态可抓取。

### 4.2 内容主题（契合你的膏方/食养商家背景）
围绕「乌梅汤/山楂六物膏/牡丹姜枣膏/酸枣仁膏/秋梨膏」写**食养科普**（非疗效宣称）：
- 例：《夏季为什么爱喝乌梅汤》《山楂六物膏的日常搭配》《酸枣仁膏与作息》
- 每篇 800–1500 字原创，配图，内链互导，利于 SEO。
- **合规**：只讲食养文化/搭配/食用场景，禁「治疗/功效/根治」等词（沿用 pdd 技能规则）。

### 4.3 广告接入点
- AdSense：文章页内文中部 + 侧边栏（2–3 个/页，自动广告起步）。
- Adsterra：Native Banner（侧栏/文末）+ 可选 Social Bar（底部，干扰小）。
- 代码通过环境变量区分：公开页才加载广告 SDK，后台页绝不加载。

### 4.4 基础设施
- **绑定自定义域名**（如 `feiyue-credit.com`），在 onrender 配置自定义域 + DNS；AdSense 必需。
- **升级 onrender 付费实例（Starter $7/月）**：避免免费层休眠导致抓取慢、广告加载失败、SEO 受损。
- `robots.txt` 允许抓取公开页、屏蔽 `/login` 后台；提交 sitemap 到 Google Search Console。
- Privacy 页含广告 cookie / GDPR 声明。

## 五、流量获取（没有流量一切白搭）

| 渠道 | 做法 | 适合 |
|------|------|------|
| SEO 长尾 | 食养科普文章铺长尾词（「乌梅汤怎么煮」），Google/Baidu 收录 | 长期被动流量 |
| 社媒引流 | 小红书/知乎/公众号发科普，文末挂 onrender 公开页链接 | 短期起量 |
| 微信内分享 | 小程序过审后，资料页放「了解更多」跳公开站（注意微信外链规则） | 复用小程序流量 |
| 邮件/社群 | 把打卡用户导到公开站订阅 | 私域复用 |

> 注意：微信内打开外链广告可能受限；建议主力流量走搜索引擎+小红书，而非仅靠微信。

## 六、收益现实预期（别被「日入$100」误导）

- **起步期（日 UV<200）**：Adsterra 月入约 **$1–10**；AdSense 未达标无收入。仅够覆盖托管费。
- **成长期（日 UV 1k+，AdSense 过审）**：食养/健康 niche RPM 约 **$2–8/千次**，月入约 **$60–240**（≈¥400–1700）。
- **瓶颈**：中文食养流量多在国内，AdSense 国内 eCPM 偏低；想高收益需英文/海外流量或高 CPC 垂直。
- **结论**：Web 广告对「赚点小费用够维护」是**可行但小额**的，预期月几十~几百元，非主要收入。

## 七、风险与坑（务必规避）

1. **onrender 免费休眠** → 升级付费或换稳定托管，否则广告/SEO 全废。
2. **自定义域名缺失** → AdSense 直接拒；先买域名绑上。
3. **疗效宣称** → 食养内容/广告文案禁疗效词，否则 AdSense 医疗保健违规封号。
4. **点击自家广告** → AdSense 永久封号且冻结余额；只放代码不碰。
5. **诱导点击/假关闭钮** → 两者都拒；广告位自然融入。
6. **机器人/刷量** → Adsterra 也禁无效流量，封号不结算。
7. **加载慢** → PageSpeed Insights 优化至 80+，LCP<2.5s，否则影响审核与填充率。

## 九、与小程序的协同

- **小程序过审**（路线1 纯个人工具）→ 接微信流量主（UV≥500，个人可开通），是**更稳的变现主线**。
- **Web 公开站**是补充：用 SEO/社媒吃搜索引擎流量，且可反哺小程序（公开页引导用小程序）。
- 两者不冲突，建议**小程序流量主为主、Web 广告为辅**。
