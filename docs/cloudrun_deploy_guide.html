1

开通微信云托管（拿环境 ID + 默认公网域名）

云托管是微信官方的容器服务，小程序用 wx.callContainer 调它，不用配 request 域名、不用 ICP 备案。

界面示意 · 公众平台 → 云托管
 微信云托管控制台
  • 概览
  • 服务管理
  • 数据库
  • 服务设置

开通云托管

第一步：开通，选按量计费

开通后会得到两个值（记下来，第⑤步要用）：
• 环境 ID（如：prod-1a2b3c）
• 默认公网域名（如：xxxx.ap-shanghai.run.tcloudbase.com）

操作步骤：公众平台 → 左侧「云托管」→ 点「开通」→ 选「按量计费」（先用多少付多少）→ 开通完成后，在「服务设置」里抄下 环境 ID 和 默认公网域名。

💡 这两个值是第⑤步小程序 env.js 必填项，先存到记事本。
2

准备数据库（腾讯云 MySQL / TencentDB）

后端数据必须存外部 MySQL（云托管容器本身不持久化文件，所以不能用本地 sqlite）。

界面示意 · 腾讯云 MySQL 购买
 腾讯云 · 云数据库 MySQL

创建后在「实例详情」拿到 内网/外网地址，填进后端环境变量

操作步骤：腾讯云控制台 →「云数据库 MySQL」→「新建实例」→ 选入门规格、库名 credit、设 root 密码 → 创建完成后在「实例详情」复制 连接地址（内网优先）。

⚠️ 后端首次启动会自动建表 + 灌种子数据（含 student01 等测试账号），你不用手动建库建表。公网连接建议把 DB_SSL=1 打开。
💡 纯本地想先试跑：用仓库自带的 server/docker-compose.yml 起一个本地 MySQL，命令见 docs/cloudrun-deploy.md 第五节。
3

部署后端镜像（上传 server 目录，平台自动构建）

把 server/ 整个文件夹交给云托管，它会按里面的 Dockerfile 自动打包成服务。

界面示意 · 云托管 → 新建服务
 新建服务

上传 server/ 目录 → 平台读 Dockerfile 自动构建 → 部署

操作步骤：云托管 →「服务管理」→「新建服务」→ 名称填 feiyue-credit-server → 代码来源选「本地代码包」并上传你电脑上的 server/ 文件夹 → 服务端口填 80 → 确认，平台会自动构建并部署。

💡 你的 Dockerfile 已写好（基于 node:22-slim，自动装依赖、监听 process.env.PORT），不用改。上传时别把 .env 一起传（已在 .dockerignore 排除）。
4

配置环境变量（DB_* / WX_* / JWT_SECRET）

数据库账号、微信凭证、JWT 密钥通过「环境变量」注入，不写进代码。

界面示意 · 服务设置 → 环境变量
 环境变量

操作步骤：云托管 → 服务 →「服务设置」→「环境变量」→ 按上图逐项添加（值来自第②步 MySQL 和第①步小程序 AppSecret）→ 点「保存」触发重启。

# 对应关系（与 server/.env.example 一致）
DB_HOST=MySQL地址   DB_PORT=3306   DB_USER=root
DB_PASSWORD=密码   DB_NAME=credit
WX_APP_ID=wx0fe78d74fdc47c1b   WX_APP_SECRET=密钥
JWT_SECRET=随机字符串(生产必须，缺失服务会拒绝启动)
NODE_ENV=production
⚠️ JWT_SECRET 必填，否则后端启动会失败。本地生成一串：node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
5

小程序侧配置（env.js 切到云托管）

改一个文件，小程序就会自动改用 wx.callContainer 调你的云托管后端。

// miniprogram/config/env.js
const IS_PROD = true;
const PROD = {
  USE_CLOUD_RUN: true,
  CLOUD_RUN_ENV: '第①步抄的环境ID',
  CLOUD_RUN_PUBLIC_HOST: '第①步抄的默认公网域名',
};

操作步骤：打开 miniprogram/config/env.js → 把 IS_PROD 改成 true → 在 PROD 里填 USE_CLOUD_RUN=true、CLOUD_RUN_ENV 和 CLOUD_RUN_PUBLIC_HOST（第①步记的值）→ 保存。

💡 改完用微信开发者工具「上传」一个新版本（如 1.0.1）即可，调用层无需改其他代码，app.js 会自动切换。
⚠️ 走云托管后，不需要在公众平台配 request 合法域名，也不需要 ICP 备案——这正是选它的好处。
6

联调 + 提审（student01 / 123456）

先在开发者工具里确认能登录、刷动态、看资料，再按上一本手册提审。

开发者工具编译→ 登录 student01/123456→ 刷动态/看资料 OK→ 上传新版本→ 提审(测号同)→ 过审发布

联调要点：开发者工具里把 IS_PROD 临时设回可联调，确认能用 student01/123456 登录、看到动态和资料；没问题就把正式版（IS_PROD=true）上传并提审。

💡 提审时测试账号仍填 student01 / 123456（同学视角，不暴露管理端），审核员用它登录验收。
⚠️ 文件上传/静态资源当前走云托管「默认公网域名」，官方建议仅用于测试；正式放量前建议绑定已备案自定义域名，或改为小程序直传 COS（详见 cloudrun-deploy.md 第八节）。
✅ 一句话路线：公众平台开通云托管（抄环境ID+公网域名）→ 腾讯云建 MySQL(credit) → 云托管上传 server/ 部署 → 填 DB_*/WX_*/JWT_SECRET 环境变量 → 改 env.js(IS_PROD=true+USE_CLOUD_RUN=true) → 开发者工具联调 student01/123456 → 上传提审 → 过审发布。全程免域名、免备案。
